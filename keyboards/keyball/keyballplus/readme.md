# Keyball+ (RP2040)

A split keyboard with 39 vertically staggered keys and 34mm track ball, low-profile (Kailh Choc) compatible.
RP2040 (SparkFun Pro Micro RP2040) port of Keyball+.

* Keyboard Maintainer: [@Yowkees](https://twitter.com/Yowkees)
* Hardware Supported: Keyball+ PCB, SparkFun Pro Micro RP2040
* Hardware Availability:
    * <https://shirogane-lab.net/>

Make example for this keyboard (after setting up your build environment):

    make keyball/keyballplus:default

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).
